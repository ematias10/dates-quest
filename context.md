# Proyecto: English Quest (Estilo Undertale)

*   **Objetivo:** SPA gamificada en Vue 3 + Tailwind CSS para repasar inglés (fechas, meses, estaciones, holidays).
*   **Mecánicas Progresivas:**
    1.  Nivel 1: Selección múltiple (Reconocimiento).
    2.  Nivel 2: Emparejamiento de festividades y meses.
    3.  Nivel 3: Ahorcado (con vidas visualizadas como el "Alma" roja de Undertale).
    4.  Nivel 4: Constructor de fechas ordenando palabras.
    5.  Nivel 5: Traducción e input de texto libre.
*   **Restricciones de Arquitectura:** Proyecto 100% estático, pensado mobile-first. Todo el estado del juego se maneja en el cliente sin base de datos ni backend.
